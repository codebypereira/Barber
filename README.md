# Suriano · Método SCULPT

Landing page de Suriano, barbeiro e educador no Porto, criador do Método SCULPT.

**Prever antes de executar.**

A página apresenta o profissional, sua trajetória e a proposta do método, que aborda geometria, formas e elevações na construção dos cortes.

## Página

- Retrato em preto e branco com o monograma SC.
- Nome em Great Vibes e assinatura do método.
- Biografia completa com destaques em negrito sobre fundo off-white.
- Bloco do Método SCULPT com a indicação “Curso em breve”.
- Layout responsivo para celular e computador.

## Tecnologias

HTML5 e CSS, com os estilos no arquivo `css/style.css`. A fonte Great Vibes é carregada pelo Google Fonts.

## Abrir localmente

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador. Mantenha as pastas `css` e `images` junto dele para carregar os estilos e as imagens. É necessária conexão com a internet para carregar a Great Vibes.

## Arquivos principais

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Estrutura e textos da página |
| `css/style.css` | Estilos e regras de responsividade |
| `images/suriano.jpeg` | Retrato de Suriano |
| `images/sc.png` | Monograma do Método SCULPT |
| `LICENSE` | Licença do repositório |

## Editar a página

Os textos estão em `index.html`, e os estilos estão em `css/style.css`. A seção `.bio` contém a biografia, e as marcações `<strong>` definem os trechos em negrito.

O endereço do curso ainda está pendente. Quando estiver disponível, o bloco `.course` pode receber um link com a chamada “Conhecer o curso”.

## Publicação

O projeto pode ser publicado no GitHub Pages a partir da raiz da branch usada para publicação. Como os arquivos são estáticos, a página pode ser servida diretamente.

Depois de enviar alterações ao GitHub, acompanhe a execução de publicação na aba **Actions** do repositório.
